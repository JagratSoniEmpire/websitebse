IMPORTANT BEFORE UPLOAD
1. Extract the ZIP on your computer first and inspect the files.
2. In Hostinger hPanel, open File Manager for blueshieldenergy.in and open its document root (usually public_html).
3. Upload the CONTENTS of this ZIP so index.php sits directly in the document root. Avoid creating an extra nested folder.
4. The website pages can display without a database, but the enquiry form requires MySQL setup.
5. Create a MySQL database and user in Hostinger. Import schema.sql in phpMyAdmin.
6. Copy config.example.php to config.php, then enter your actual database host, database name, username and password.
7. Do not share config.php or publish database credentials. If your host provides a different database hostname, use the value shown in hPanel.
8. Submit a test enquiry and check that a new row appears in the enquiries table.
9. Check desktop and mobile layouts, all links, email and phone buttons, and SSL/HTTPS.

ENQUIRY FORM
- Saves the submitted form to MySQL after config.php is configured.
- Does not send email notifications yet.
- If database configuration is missing or incorrect, it redirects to an error message.
- Enquiries can be viewed using phpMyAdmin. No public admin/login panel is included in this first version.

EDITING CONTENT
- Edit page text in the relevant .php file.
- Main visual styles are in assets/css/style.css.
- Navigation behaviour is in assets/js/main.js.
- Current solar photographs are remote Unsplash images used as temporary illustrative images. They are not Blue Shield Energy's own projects. Replace them with approved company photos when available.
- The logo mark in this version is a CSS text-based placeholder inspired by the supplied logo. Replace it with your original logo file for an exact brand match.
- Add project photos and verified project facts to projects.php when ready.
- Do not publish customer quotation names, addresses, phone numbers, private prices or customer-specific details.

CONTENT / CLAIMS
- Warranties, equipment, scope, fees, approvals and subsidy eligibility are project- and rule-specific. This starter avoids promising the same terms to every customer.
- PM Surya Ghar links to the official portal. Check current government requirements before publishing detailed eligibility or subsidy claims.

EXTERNAL ASSETS
- Google Fonts and Unsplash images require internet access.
- For full control, download licensed/approved images and host them in assets/images, then update the image paths in the PHP/CSS files.

This is Version 1 intended for further editing. Test on the live hosting account before treating it as production-ready.
